# Roadmap

## v0.1.0-alpha.1 — implemented in source

Portable schema, deterministic extraction, structured review, five Markdown exporters, and synthetic regression tests.

## Near-term maintenance

- Expand interoperability fixtures across all five export targets and add independently evaluated behavioral tests.
- Define consent, retraction, and deletion semantics while preserving lifecycle history and auditability.
- Prototype optional provider-assisted candidate extraction behind proposed-diff review, with deterministic offline extraction remaining the required baseline.

## Possible later work

- Carefully scoped vendor import adapters.
- Additional schema and exporter compatibility research based on real interoperability evidence.

These are directions, not commitments.
