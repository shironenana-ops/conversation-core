# Privacy

Use Conversation Core only with conversation logs you have permission to process. Public fixtures in this repository are synthetic.

Conversational patterns may be wrong, outdated, oversimplified, private, or sensitive. Human review is required before activation or migration. Do not use this project to infer protected or sensitive attributes or to create medical, psychological, political, religious, sexual, or criminal profiles. Emotional language is not a diagnosis.

Deleting source data does not automatically delete derived cores, exports, backups, or downstream copies. Each derived artifact must be explicitly reviewed and deleted or retracted. Local imports and private exports are ignored by Git, but users remain responsible for access control and secure deletion.
