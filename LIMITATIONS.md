# Limitations

- The heuristic extractor recognizes explicit markers; it does not understand arbitrary conversations.
- Repetition is only a weak signal and does not prove a durable preference.
- Conflicting, ambiguous, and isolated evidence requires human judgment.
- Export adapters format the same reviewed core and cannot guarantee target-model behavior.
- Scope filtering is label-based, not a policy enforcement boundary.
- Retraction affects newly generated exports, not artifacts already copied elsewhere.
- No vendor import adapters, natural-language revision, database, UI, hosted service, or paid provider integration are included.
- Schema validation checks structure and active-item provenance, not truth or consent.
